# TTS Converter Desktop
<img width="1273" height="942" alt="image" src="https://github.com/user-attachments/assets/b39b8d99-2fcf-4998-b1ad-885a8c462a55" />

TTS Converter is a desktop tool for local speech synthesis using the Supertonic and Kokoro-ONNX engines, with optional support for speech conversion via RVC. RVC processing runs in a user-configured isolated Python environment, keeping heavy RVC dependencies separate from the main application. Therefore, to use RVC, you may want to download the rvc_env.zip file, which contains all the dependencies for infer_rvc_python.

TTS Converter é uma ferramenta desktop para síntese de voz local com os engines Supertonic e Kokoro-ONNX, com suporte opcional a conversão de voz via RVC. O processamento RVC roda em um ambiente Python isolado configurado pelo usuário, mantendo as dependências pesadas do RVC separadas da aplicação principal. Portanto, para usar o RVC, você pode querer baixar o arquivo rvc_env.zip, que contém todas as dependências do infer_rvc_python.
